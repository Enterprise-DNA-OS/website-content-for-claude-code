# Why the content desk has no front end

An editor can describe the change, inspect the record, revise it and review the result through an agent. A database stores arbitrary content, references and exact revision evidence. Read-only HTML shows the week and the review queue. A local JSON bundle hands approved content to the existing website's build process after an adapter is implemented.

A visual editor provides a different experience: live page previews, drag-and-drop layout, rich-text widgets, image selection and multi-person collaboration. Mobile editing and offline conflict handling also need specific interfaces. This base provides none of those. Portable Text and assets are retained as records, not converted into a new site.

Enterprise DNA builds the editing screens, media storage, identity checks and delivery adapter the owner actually needs into the custom version. The database remains theirs. One setup fee, then a retainer through Omni by Enterprise DNA.
